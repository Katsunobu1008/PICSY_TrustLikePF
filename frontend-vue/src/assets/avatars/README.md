# Avatars

Drop circular avatar images for dashboard actor cards in this directory.

- Supported formats: `.png`, `.jpg`, `.jpeg`, `.svg`
- Name files with the actor UUID (e.g. `11111111-1111-1111-1111-111111111111.png`) or the handle (e.g. `alice.png`).
- Images are automatically detected at build time; missing files fall back to initials.
