# ゾクゾク / ZOKUZOKU UX Prototype

**好きがゾクゾクと。** 生成AIによるグッズ企画・作品継承・購入意思表示・企画者向け分析を操作できるWebプロトタイプです。

## 起動

Node.js 20+ が必要です。外部依存パッケージはありません。

```bash
npm start
# http://localhost:4173
```

`npm test` で簡易的なロジックテストを実行できます。

### 実際の生成AIを接続する場合

```bash
# macOS / Linux
export OPENAI_API_KEY='your-key'
export OPENAI_IMAGE_MODEL='gpt-image-2'
npm start
```

Windows PowerShell では `$env:OPENAI_API_KEY='your-key'; npm start` です。サーバーの環境変数でキーを管理し、ブラウザに公開しないでください。AI接続時のAPI利用料金は別途発生します。モデル提供やアカウント条件によって利用できないことがあります。

## 操作シナリオ

1. **みつける**：種になる作品を4つ表示。商品カテゴリーで絞り込み、検索、人気順表示
2. **リミックス**：気に入った作品から「リミックス」を押す。引用元の系譜を引き継ぐ
3. **つくる**：商品カテゴリー・プロンプト・テイストを選び「グッズを生成する」
4. **公開**：作品を公開し、みつける/マイ作品に反映
5. **欲しい！**：数量を選んで疑似購入意思を登録（決済・注文なし）
6. **インサイト**：カテゴリ別作品、派生関係、模擬購入意思を確認

## デモと実運用の境界

- **デモモード**：SVGテンプレート画像を返します。生成AIではありません。画面に明示します。
- **AIモード**：`OPENAI_API_KEY` があると Images APIにテキストからの画像生成を要求します。モデル利用権限と残高が必要です。
- **リミックス**：引用元IDと参考プロンプトを引き継ぎますが、**画像ピクセルのImage-to-Image編集は未実装**です。
- **購入予約**：ブラウザ内の疑似記録。決済・金銭の徴収・在庫確保・注文処理を行いません。
- **PICSY**：評価行列・カンパニー・購買力計算はこのMVPでは実装していません。作品の親子関係は保存します。
- **認証・DB**：デモはブラウザのLocalStorageを使用します。共有アカウントや個人情報を保存しないでください。
- **IP**：既存の商用作品を無断で二次創作・販売しないでください。サンプルはオリジナルの架空動物です。
- **商用化前の必須事項**：IPのライセンス範囲、生成/公開/販売審査、本人確認、決済、個人情報、監査ログ、不正対策、脆弱性診断、サーバー側保存、AI安全対策、コスト管理。

## 技術構成

- Vanilla JS / CSS / HTML + Node.js `http`（パッケージ依存なし）
- `GET /api/status` モード確認
- `POST /api/generate` `{prompt,kind,style}`（最大700文字、IP別の本格権利審査は未実装）
- `shared.mjs` デモデータ・SVG生成、プロンプト検証
- `tests/` Node標準テストランナー
- ローカル保存はデモ作品・疑似予約のみ。AI画像Base64は保存しません。

## 現場検証における推奨順序

① ファンの既存グッズ不満の定性調査 → ② 生成・比較・改良の観察 → ③ 購入意思の条件付き取得 → ④ IP許諾済み試作品 → ⑤ 価格別実需要実験 → ⑥ 創作継承の経済効果（PICSY）検証。
